# 词汇 · HSK 3.0 vocabulary review

A calm, mobile-first web app for reactivating Chinese vocabulary. One word at a
time, nothing else on screen until you ask for it. Swipe right when you know
it, swipe left to reconsider the previous word, tap ☆ to keep a word for later.

The first collection is the complete official HSK 3.0 word list from
《国际中文教育中文水平等级标准》(GF0025-2021): 11,092 entries across levels
1–6 and 7–9, with the official pinyin and a concise Chinese-only definition.

## Run it

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # deck logic tests
npm run build      # static site in dist/
```

The build uses a relative base path, so `dist/` can be served from any folder
or sub-path (GitHub Pages included). `.github/workflows/deploy-pages.yml` at
the repository root publishes it to GitHub Pages under `/vocab-review/`.

## How it works

The vocabulary is one persistent shuffled deck. On first launch the word ids
are shuffled once and that order is stored. Swiping right marks the active
word reviewed and advances one card; swiping left steps back one card and
takes back its review. Because the deck order never changes, going back and
forward again always shows the same words in the same sequence.

Everything is persisted in `localStorage` after each change: deck order,
reviewed ids, saved ids and the current position. Closing or refreshing the
app resumes exactly where you were. Saved words are independent from review
progress and survive a progress reset; only "Reset all data" removes them.

## Architecture

```
src/
  domain/      vocabulary types + pure review logic (no React, no storage)
    types.ts       Collection / Word
    review.ts      ReviewState, moveForward, undoPreviousReview, toggleSavedWord, ...
  storage/     persistence: StorageAdapter (localStorage today), ReviewStore
  data/        collection registry + loader (public/collections/*.json)
  app/         React bindings: session hooks, hash router
  ui/          screens and components
```

A `Collection` is any list of `Word`s (`written_form`, `pronunciation`,
`definition`, free-form `metadata`). HSK 3.0 is just the first entry in
`src/data/collections.ts`; other Chinese lists or other languages can be added
as further JSON files without touching the review logic or the UI. The domain
layer is also where a future "review saved words" mode plugs in: it is a
second deck built from `state.saved`.

## Vocabulary data

`public/collections/hsk30.json` is generated by `scripts/build_hsk30.py`:

* Word list, official pinyin, part of speech and level come from the
  official HSK 3.0 list (via the cleaned-up `ivankra/hsk30` CSV).
* Chinese definitions are hand-written, concise, dictionary-style glosses
  stored in `scripts/overrides/*.json`, keyed by the official HSK id.
  They take precedence over the open dictionary data the script can fall
  back to.

```sh
npm run data       # rebuilds public/collections/hsk30.json
```
